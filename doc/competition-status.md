# 赛题、资源与当前进度

用户已实板确认人工横向补偿后的画面正常、BGM 无杂音、游戏可玩。当前已恢复同位流内的素材预览、手动切图／轮播、动态字幕、音频波形与显示设置，构建及配套检查通过；恢复版仍需新一轮实板验收。旧 A/B/C 兼容性探针只保留为历史，不再作为当前候选。

游戏、图库和叠层共用横向补偿，默认 128，输出固定 640×480，不切换 HDMI 分辨率。启动共享 BMP 解码器先验证并锁定游戏纹理，再扫描图片、向 SDRAM 四槽预取；游戏不等待图库缓存就绪。音频优先取得 SD 扇区，正常的原厂 HDMI／DDC／PHY 与 PCM 链路保留。操作以 [板上操作](board-demo.md) 为准。

## 游戏与素材边界

自研 RTL 游戏参考可追溯的 Area6／E_GroundArea6：212 格、三坑、六管、17 个敌人生成点。包含四敌槽、成长／火焰／星／1UP、龟壳／双火球、多币砖、100 币加命、砖块上弹／碎片／变身闪烁／上浮奖励、死亡动画、滑旗入城与时间换分。公开输入通关 1451 世界步、15 跳、终点 x3264，不使用内部传送。它不是 FC 模拟器，不声称原作逐帧一致；地下奖励房和烟花仍未实现。

一路 BGM＋四路 SFX 从 TF 流播，24 轨离线转换为 48kHz s16le mono，HDMI 两声道输出相同混音。默认有声，主／BGM／SFX 为 3／2／3；星音乐替换、死亡／触旗停 BGM、重生重播。音频来源、固定提交与逐轨哈希见 assets/audio/manifest.json 和 [来源说明](code-provenance.md)。

六张 BMP 依次为 640×480、320×240、800×600、641×479、640×480、960×720。首图含图集和签名，后五图展示角色、地形、敌人道具、头像、素材索引。昵称六字符、头像八种；前十排名使用独立用户 Flash 的 0x600000／0x601000 双日志、CRC 和最后提交，仿真通过不等于掉电实测。
