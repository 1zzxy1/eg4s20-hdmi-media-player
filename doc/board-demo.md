## 当前控件

| 控件 | 用途 |
|---|---|
| KEY3 按住 | 游戏左走 |
| KEY2 按下／按住 | 跳跃／高跳；下一跳先松开 |
| KEY1 按住 | 游戏右走 |
| KEY1＋KEY3 | 大角色下蹲 |
| SW4 上拨 | 加速；火焰形态发射火球 |
| KEY4 | 首屏进入昵称；昵称长按一秒开始；死亡演出结束或结算后确认 |
| SW1 上拨／下拨 | 全局静音／有声 |
| SW2 上拨 | 仅首屏独立 1kHz 测试音 |
| SW3 | 暂无功能 |

昵称界面 KEY2／KEY3 改字符，KEY4 短按确认下一位，六位后选头像再确认；任何位置长按 KEY4 一秒可快捷开始。KEY1 在昵称／排行返回，在游戏中只用于右移，不打开暂停或 Debug。声音默认开，主／BGM／SFX 固定 3／2／3。

| 指示灯 | 含义 |
|---|---|
| LED1 | SD 初始化完成 |
| LED2 | 游戏图集完整、签名正确，已发布到像素域 |
| LED3 | 图集重试失败／音频读卡错误／排行 Flash 错误的组合指示 |
| LED4 | 原厂 HDMI 核视频输入背压异常锁存 |

LED4 在 HDMI 锁定后记录有效视频未被接受的情况；它不是音频溢出指示。LED3 若仅因图集失败亮起，图集最终成功后可清除；音频／Flash 错误按各模块行为保持。重新配置可清除系统锁存。

## 本版做了什么

依据马里奥之前的旧工程恢复原厂 HDMI 核、上电 EDID 触发和真实 DDC 连接；此前一次原厂候选缺少这两个接法。固定 25MHz、800×525、640×480、约59.524Hz，48kHz 双声道24-bit LPCM、N6144／CTS25000；不动态切输出分辨率。

首张 BMP 直接解码到纹理缓存，不再等待 SDRAM／帧 DMA／显示确认。读取成功后停止图片访问，再启动一路 BGM＋四路 SFX。图片失败可重试，仍不保证 SD 热插拔或永久不返回扇区的自动恢复。没有添加负坐标偏移补偿。

当前 Slice72.81%、BRAM81.25%，原生 setup +4.053ns／hold +0.011ns。资源变化和数字测试通过不能证明杂音／环绕的实板根因，仍须上述实测。

## 其他验收边界

游戏保留砖块／道具／敌人／火球、死亡、滑旗入城、昵称与排行。排行使用独立用户 Flash 的 `0x600000/0x601000` 双日志，掉电恢复仍待板测。

先通过 SRAM 声画验收，再按 [固化说明](bringup.md) 写配置 Flash W25Q16；不要选到排行榜用的用户 Flash W25X64／W25Q64。固化冷启动及至少60分钟长稳仍未验收。本版不是完整赛题展示位流，媒体扩展待基本声画稳定后恢复。
