# 板上操作

## 下载和启动

使用 HDMI-A、原 mini-HDMI→HDMI 线和原 V4 SD 卡。执行 README 中的构建及部署检查，下载 `prj/media_player_Runs/phy_1/media_player.bit`；不要下载旧 A/B/C 诊断位流。恢复功能的新版仍需用户实板验收，旧对齐版正常的反馈只适用于对应旧位流。

1. SW 全下，上电等待 LED1（SD 初始化）及 LED2（完整游戏图集验证）。
2. 先听 BGM、看首屏是否仍对齐。默认源补偿为 128，音量主／BGM／SFX 为 3／2／3。
3. 首屏按 KEY4 进入昵称，松开后再次长按 KEY4 一秒快捷开始；也可逐字确认六字符、选择头像后开始。
4. 游戏 KEY3 左走、KEY2 跳／高跳、KEY1 右走；KEY1＋KEY3 大角色下蹲；SW4 加速／火焰形态发火球。
5. 昵称界面 KEY2／KEY3 改字符，KEY4 确认，KEY1 返回。进入昵称后 Debug 禁用；回到首屏才可使用素材和设置。

素材和音频均未改变，SD 卡无需重写。本次不自动烧板、固化或写实体卡。

## 首屏实验室

| 选择 | 操作 | 应观察到 |
|---|---|---|
| SW1 上拨 | KEY2 上一张、KEY3 下一张、KEY1 暂停／继续 | 素材图自动每 3 秒切换一次；显示 AUTO:ON／PAUSED、图片编号与 CACHE 数量；上电已后台预取，CACHE:5 后当前图、上一张和后三张驻留，缓存命中无需重读；连续跳出窗口仍可能等待 |
| SW2 上拨 | 首屏或游戏中，可与 SW1 合用 | 底部移动字幕随素材库、关卡位置、大马里奥和通关变化；PCM 波形、零线、幅度网格、48kHz／1.33ms／X2 标注和电平条 |
| SW1＋SW3 上拨，SW4 下拨 | KEY2／KEY3 选项，KEY1 修改 | FULL IMAGE 整图／CENTER 2X 中心放大、量化色彩、测试图、亮度、对比度、CUT／FADE／WIPE、复位显示设置 |
| SW4 上拨 | KEY2／KEY3 选项，KEY1 修改 | 声音开关、主／BGM／SFX 音量、音效编号／试听、1kHz 测试音及欠载／丢弃计数 |

SW4 音频页优先于其他设置；SW2 单独打开时主要观察叠层，切图操作需 SW1。KEY4 在首屏实验室也能进入昵称，无需先退出设置。波形来自输出 PCM，不是动画替代音频。图库扫描失败不应阻塞游戏图集或首屏进入流程。

音频设置的测试音只用于首屏，进入昵称后自动关闭；音量值可保留。SW1、SW2 已恢复上述实验室用途，不再沿用排障版“SW1 静音／SW2 测试音”的映射。

显示页第一项按 KEY1 实时放大，再按一次实时缩回。图库读取已缓存整帧，在下一帧切换整图／中心 2 倍模式，不重新读卡、不清空缓存。演示时可先在图库按 KEY1 暂停轮播，再打开 SW3，保留同一张素材反复演示缩放。轮播的 3 秒从切换完成且导航空闲后计时，首次加载／转场可能延长实际间隔。

## 横向补偿

本次录制版为实时缩放腾出资源，移除交互校准入口和校准页显示，固定使用实板确认正常的 128 像素补偿。SW3 单独上拨不再进入校准；SW1＋SW3 仍打开显示设置。该补偿同步用于游戏、图库、菜单和字幕。输出保持 640×480，整图／中心放大均铺满输出，游戏沿用原有两种逻辑视口，不切换 HDMI 分辨率。

## 验收顺序

先检查游戏画面／跑跳和 BGM，再进入素材页等待缓存，反复切换并听有无音频欠载；随后打开字幕／波形、实时放大和缩回、调整显示参数和转场。检查素材图四边是否完整，最后再次进入昵称并长按开始。建议另测冷启动、持续运行及排行掉电恢复。

LED3 为图集／音频／Flash 错误汇总，LED4 锁存原厂视频入口背压异常；LED2 只证明游戏图集发布，不代表图库五槽已满。数字仿真无法代替实屏和试听验收。
