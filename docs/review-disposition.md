# 只读复核处理记录

采用用户指定的 `LV.3★deepseek★OpenCodeGo/deepseek-flash`，只读规划与复核，主代理负责最终裁决。所有“完成”均由实际工具结果支撑，不以子代理口头意见替代测试。

| 发现 | 裁决与处理 |
|---|---|
| `FEATURE_SCALE=0` 未移除缩放算法 | 有效，增加固定尺寸直接读取分支和常量几何运算；严格模式分别测试拒绝非匹配尺寸与匹配尺寸成功；重新跑资源矩阵 |
| 首图失败后只能人工恢复 | 有效，增加有界自动跳过坏图；全部候选失败后停止连续重试，保留手动请求。新增调度器故障恢复测试 |
| 缺 BMP→真实 FIFO 的组合测试 | 有效，增加 `test_vendor.py --bmp`，连接缩放器、真实异步 FIFO、原厂加密 SDRAM 控制器、器件模型和完整显示回读 |
| DMA 没有使用 busy/refresh | 有效且已复现：原厂控制器仿真出现无效写数据。加入突发开始门控后整帧回读通过；不是修改模型让错误消失 |
| 缺短扇区中途失败测试 | 有效，增加已产生部分像素后短扇区中止的用例；不允许提交半帧 |
| 字幕首字母缺失 | 黄金测试复现；33 字符常量赋给 32 字符寄存器导致截断，改为 32 字符 |
| 字幕应反转移位方向 | 不成立。Verilog 字符串首字符位于最高字节，`(31-index)*8` 正确提取正序；反转会制造镜像。整帧黄金比对证实正序 |
| 测试引用不存在的参数 | 复核快照过时。参数已透传，真实 Icarus/ModelSim 编译与公开按键接口驱动测试通过；没有强制内部寄存器 |
| 有符号饱和可能依工具而变 | 十进制无尺寸常量的规则可确定，不能当作已证实缺陷；仍显式写有符号常量并用全部对比度档位黄金图像覆盖 |
| 新 BUFG 使 SD 域没有约束 | 不成立。TD 报告明确列出 clk50=50MHz，以及 `u_loader/bmp_read_m0` 的20ns路径；不新增重复时钟掩盖实际传播 |
| FIFO 9位端口接10位wire必为X | 不成立，Verilog进行零扩展；改为显式9位原始计数及补零，真实FIFO回读通过。旧文档“修复截断”的表述予以纠正 |
| 异步复位释放未同步 | `write_release` 已是异步断言、三拍同步释放结构；标记 ASYNC_REG。不得改为直接跨域传输 ready |
| 原厂IP无法仿真 | 绝对表述不成立。ModelSim实测可编译并运行原厂加密HDMI/SDRAM控制器；SDRAM器件模板确实没有可用阵列行为，另接明确标注的自建器件模型 |

保留限制：纵向放大可能重读源行所在扇区；仅正高度24-bit BI_RGB、连续文件；波形为64点短窗而非FFT；没有模拟电气眼图、真实卡异常电气行为、完整HDMI音频接收器或实板验证。等待显示确认时不强行超时复用旧bank，避免错误恢复破坏缓存所有权。
