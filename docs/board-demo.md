若旧工程RUN报`BIT-8123 ... unconstrained io(s)`：查看实际run的`settings.cfg`是否出现空`ADCList`/`SDCList`。本轮已用原生工程API修复并实际运行成功，验证文件在`build/td_gui/verification.json`。不要通过允许未约束IO来绕过错误；SD卡内容与这次编译错误无关。

## 控件配置

以下“上/下”按开发板手册第18页的标准摆放，SW上=1、下=0。转动板卡后应按丝印编号识别，勿凭左右猜编号。

| 控件 | 引脚/类型 | 当前功能 |
|---|---|---|
| KEY1 | A2，低有效 | 复位播放器；重扫卡并回到首图；轮播关闭、对比度100%、FADE、计时归零。亮度/叠加仍按拨码位置生效 |
| KEY2 | B2，低有效 | 下一张；按下触发，等待加载/转场结束再按，快按不保证排队记录每次请求 |
| KEY3 | B1，低有效 | 自动轮播开/关；初始关闭。每张图提交完成后约等1秒再开始下一次加载，实际周期还包含读卡与转场 |
| KEY4短按后松开 | C1，低有效 | 对比度100%→50%→150%→200%→100%；建议按0.1～0.5秒 |
| KEY4长按后松开 | C1，低有效 | 保持约1.5秒后松开，FADE↔WIPE；只改转场模式，不切图，随后按KEY2演示 |
| SW1 | C8 | 亮度低位，见下表 |
| SW2 | C7 | 亮度高位，见下表 |
| SW3 | C6 | 上=开启计时/字幕/参数面板，下=关闭文字层 |
| SW4 | C5 | 上=开启波形/峰值，下=关闭波形层 |
| CONFIG1 | T2 / PROGRAM_B | FPGA重新配置按钮；不是应用复位。仅JTAG下载后按它会退出当前易失配置，并尝试按板级启动配置重新加载；未固化时不要拿它演示KEY1功能 |
| BUZ/SW | 蜂鸣器硬件通断 | 拨到关闭/断开位置（手册：上断开）；本工程不驱动蜂鸣器。测试音从HDMI显示器/电视/音箱输出，此开关不控制HDMI静音 |
| DIG/LED | 显示硬件选择 | 选DIG（手册：上）作为统一演示位置。本工程未驱动8位数码管/8组双色LED，两档均不改变播放器功能，也不影响四颗独立状态LED |

| SW1 | SW2 | 亮度 | 面板 |
|---|---|---|---|
| 下 | 下 | 不偏移 | B+00 |
| 上 | 下 | +32 | B+32 |
| 下 | 上 | +64 | B+64 |
| 上 | 上 | −32 | B-32 |

建议开始位置：**SW1下、SW2下、SW3上、SW4下，BUZ关闭，DIG/LED选DIG**。之后按KEY1一次。画面应显示`B+00 C100% FADE`；若不同，先核对拨码编号和方向。

## 逐项演示（每步完成后自行打勾）

1. [ ] 基础显示：下载位流并按KEY1，等待首图出现；图像无上下颠倒、错色、闪屏。先不要开启自动轮播。
2. [ ] 文字层：SW3下→上，字幕/时间/参数面板随之关闭/开启；等几秒确认时间递增、字幕移动，背景能透过半透明区域看到。
3. [ ] 手动切图：按KEY2，等画面稳定后再按，循环观察四张图；默认FADE应先变黑再出现下一图。
4. [ ] 显影：保持SW3上，KEY4按住约1.5秒再松开；确认面板显示WIPE，再按KEY2观察逐步显影；长按松开可切回FADE。
5. [ ] 缩放：使用所提供混合尺寸镜像，逐一切图；不同源尺寸均填满固定640×480输出区，不要求显示器报告分辨率改变。显示器自身的全屏拉伸不算FPGA缩放证据。
6. [ ] 亮度：按SW1/SW2表切换四种组合，对照面板B值与图像明暗；完成后回到两者下。
7. [ ] 对比度：KEY4短按并松开，每次检查C100%/C050%/C150%/C200%及画面对比度；四次后回到C100%。
8. [ ] 音频：显示器/电视必须支持HDMI音频或有对应音频输出，先低音量；应听到连续1kHz测试音。听到音调不能单独证明48kHz，采样率需接收端信息或分析设备确认。
9. [ ] 波形：SW4上，应出现绿色波形及峰值条，SW4下消失；1kHz周期信号的波形/峰值可能稳定，不要求随机跳动。此层显示内部PCM，看到波形不能替代实际试听。
10. [ ] 轮播：按KEY3开启，等待多次自动切换，再按KEY3关闭；在途加载可能继续完成一次，之后应停止自动切图。
11. [ ] 复位：按KEY1，首图重新加载，计时归零，C100%、FADE、轮播关闭；不按CONFIG1。
12. [ ] 固化/冷启动：完成上面各项后再进行W25Q16配置Flash固化和至少十次冷启动。本轮不执行此项。

## 四颗独立LED定位

手册第6页图2-3确认高电平点亮，程序已按该极性修正。

| 灯 | 亮的含义 |
|---|---|
| LED1 / A4 | SDRAM初始化完成 |
| LED2 / A3 | 已提交可显示的完整首帧 |
| LED3 / C10 | HDMI核锁定输入视频时序，不等于显示器已收到信号 |
| LED4 / B12 | 发生AXIS就绪违约，保持亮直到KEY1复位 |

正常播放预期前三亮、第四灭。若只有背景和OSD、LED2不亮，优先检查卡及镜像；若前三亮但显示器无画面，核对HDMI-A、显示器输入和线缆；LED4亮则记录状态继续排查。不要把电源灯、DONE灯或8组双色LED当成这四颗灯。

依据：`赛题/HX4S20开发板手册-HDL版2410.pdf`物理第6、14～19页；`官方资料/3_原理图/开发板原理图/3_Power_and_Config.pdf`第1页Config1→PROGRAM_B，以及`6_EX_DEVICE.pdf`第1页。手册与原理图的蜂鸣器开关位号存在SW5/SW7差异，操作按BUZ/SW丝印及功能识别。
