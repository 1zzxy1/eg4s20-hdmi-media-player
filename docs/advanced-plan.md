# 五项扩展实施契约

基线 `5c950b2`。先实现全部五项，由用户在获得资源报告后决定保留项；构建 profile 仅用于对比，全部功能必须能整合在同一顶层。原始资料保持只读。

1. 图层：内置字模、上电计时、滚动字幕、半透明参数面板，帧内内容稳定。
2. 转场：淡出至黑/切换/淡入和有方向的显影，只有黑屏边界才允许切换 bank，首帧不等待淡出。不把单源显影描述成两图交叉混合。
3. 缩放：24-bit BI_RGB BMP，正高度，宽 1..1920、高 1..1440；正确处理行填充、跨扇区像素和像素偏移。加载侧最近邻缩放至 640×480，保留底向上输出及 SDRAM 写侧翻转。只读所需扇区，缓存命中复用，输出具备背压。
4. 参数：保留四档加性亮度，新增四档中心化对比度；KEY4 短按调对比度，长按切转场模式。数值 OSD 与实际处理参数使用同一帧快照。
5. 可视化：抽取实际 48kHz PCM，双 bank 波形及峰值指示，每帧发布完整快照。时间戳为上电计时，不是实时时钟。

验证接口：扇区请求/响应→BMP缩放RGB；真实异步FIFO→帧DMA→有延迟/刷新/忙状态的内存模型；时序→效果→AXIS。比较独立 Python 生成的整帧黄金像素；检查复位、背压、坏头/短扇区/超时、缓存所有权与帧内参数稳定性。保留旧测试回归，新增负例证明检测器有效。

所有模型必须声明作用边界。Icarus 不能解密厂商 HDL；黑盒展开不等于功能验证。加密 IP 是否具有可运行模型由合法现有仿真器实际编译/运行决定，不能只根据明文端口模板推断“没有模型”。功能仿真、模型集成、原厂IP、布局布线、硬件测试分别报告。

子代理报告是建议，以下不直接采纳：9位端口连接10位wire并不自动产生X（Verilog会扩展）；单次Fmax报告不能证明所有更高频实现均不可能；流水延迟只要所有数据/同步一致即可由接口验证，不能未经证据断言必须恰好25拍；资源是否足够以TD实测为准。
